# `art/reference/` —— **观感参考**（不是资产、不进判据）

这里放"想做成什么样"的参考图。它们与 `art/anchor/` 的判据图是两件不同的事：

| | `art/anchor/` | `art/reference/`（这一格） |
|---|---|---|
| 是什么 | **判据**：本管线自己烘出来的产物（像素 + 文件字节） | **目标**：别人的图，说明"看着该像什么" |
| 有哈希吗 | 有（`hashes.txt` §一/§三，重登记要写根因） | **没有**，改它/删它不触发任何键、不影响任何测试 |
| 用途 | "改坏了没有" | "接下来往哪改" |

## 三张（2026-09-20 存，用户给的；前两张指气态巨行星，第三张指月球）

### `gasgiant-saturn.png`（474×444，sha256 前 16 `4C19105B3E51DA26`）

土星（带环 + 卫星凌日/投影，奶黄条带，晨昏线很宽很软，极区偏暗）。

**从它抄什么**：① 条带是**几乎看不出边**的过渡，只有细丝状的涡流破坏规则性；
② 明暗交界占球面很大一块（半透气体的包裹漫反射），不是一条刀切的边；
③ 亮带偏白偏暖、深带偏棕，饱和度低；④ 环与卫星投影是"次要但很认得出"的特征。

### `moon-real.webp`（474×474，sha256 前 16 `33CFE9162FD92458`，2026-09-20 用户给的）

真实月球（残月 + 地球反照）：**中性灰**的风化层、**成片麻点状的小坑**、坑缘与溅射纹偏亮、
**月海**是平坦而略偏冷的暗块、晨昏线上一眼能看出地形起伏、暗面不是全黑（地球反照的微光）。

**从它抄什么**（对应 `23` 的 V5/V6）：① 坑的**密度与尺度层次** —— 参考图里小坑多到成"麻点"，
今天只有三层、近看偏平；② **坑缘/溅射纹提亮**（今天坑缘只比基底亮一点点）；
③ **月海**是"平坦 + 暗 + 略偏冷"的**块状**区域，不是按高度阈值切出来的一圈；
④ **位移幅度**要够（否则晨昏线上看不出地形）；⑤ **暗面的地球反照**（暗面不是 0）。

⚠ **来源**：用户提供的图（看起来是一张真实月面摄影/合成，**未核实**出处）⇒ 同下面那条：
只当**观感目标**，不许再分发、不许当纹理资产用。

### `gasgiant-uranus.png`（327×329，sha256 前 16 `CA5D6FFC07BE4056`）

天王星（淡青、近乎无特征，只有一条极淡的亮带；晨昏线极宽）。

**从它抄什么**：① **低对比**也能好看 —— 不是非得画满条带；② 颜色可以完全换一档
（`absorption` 三通道给"蓝吸得少"就是青）；③ 边缘一圈非常薄的亮边。

⚠ **来源**：土星那张看起来是 NASA/JPL/SSI 的 Cassini 合成图（**未核实**）；
天王星那张右下角带 `昵图网 www.nipic.com` 水印 ⇒ **来源不明**。
⇒ 两张都只当**观感目标**：不许再分发、不许当纹理/贴图资产用。
（`px render` 不会读到这一格；管线里没有任何一处引用它。）

## 怎么用（一轮视觉迭代的流程）

```bash
# 1) 改观感旋钮：气态巨行星的材质旋钮在场景配方里，条带结构在图的参数里
#    art/scene/orbit-gasgiant.toml  → absorption / wrap / thickness / limb / band_* / albedo
#    art/gasgiant/*.toml             → bands（圈数/对比）/ turbulence（相位扰动）
#    月球那一档：art/moon/*.toml（陨坑的层数/半径/深度、色板那条 height 的收口）
#               art/scene/orbit-moon.toml（palette= moon / displace / sea_level）
# 2) 重烘 + 出同机位图
px run gasgiant --build
px run scene orbit-gasgiant
px_render --offline --scene <产物> --out target/shot-gasgiant.png --width 960 --height 640
#   月球：px run moon --build → px run scene orbit-moon → px_render … --out target/shot-moon.png
# 3) 与参考图并排看；能记下来的量化读数只有"条带圈数 / 值域 / 均值 / 边缘带宽 / 坑的密度"
```

⚠ **不要**把参考图当逐像素靶子：它不是本管线的产物，分辨率/相机/后期都不同。
"像不像"这件事的判据是**并排看 + 说清改了哪一栏、读数怎么动**（写进笔记）。
