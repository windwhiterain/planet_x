# 参考图（**源输入**，进版本库）

这些是美术方向的**源输入**：别人拍的/画的太阳。它们**不可再生** ⇒ 进版本库。
（反面是 `/scratch` 里那些裁图、放大图、`*.stats.json` —— 那些由这些源图 + 脚本**可再生产**，
所以**不**进版本库。见仓库根 `.gitignore` 的 `/scratch`。）

⚠ 它们**不进构建**：`web/static/` 是发布面，参考图只给人和工具看。

## 怎么用

```bash
node scripts/shots/refstat.mjs refs/sun3-loops.png              # 分位数 + 径向剖面 + 日珥外沿
node scripts/shots/refstat.mjs refs/sun3-loops.png --box 120,240,520,220   # 只量一块矩形（特写）
node scripts/shots/refstat.mjs scratch/shots/sun-limb.png refs/sun3-loops.png   # 并排比
```

`refstat.mjs` 是**为参考图写的量具**（自带的 `run.mjs --stats` 量的是我们自己渲染的图：
它知道相机、知道圆心半径；参考图得先自己找圆心）。`--disk cx,cy,R` 手动给圆心是必要的：
自动找日面时包围盒会被侧面伸出去的日珥撑大（SDO 那张自动量出 R=121.5，真值约 112）。

## 三张各自在定什么

| 文件 | 来源 | 定的是 |
|---|---|---|
| `sdo-304.png` | SDO/AIA 304Å 真日面（474×289） | **形态与配色的锚**：日珥的须、临边增亮、日面亮度分布 |
| `sun2.png` | 高对比艺术渲染（736×494，sha256 `b9688123be378…`） | **亮度层次**："光从里往外迸发"的观感、白热核；**大尺度结构** |
| `sun2.png` | 见上 | 同一张。用户后来又发过一次"日面特写（大弧 + 暗腔洞 + 亮核 + 很软的日缘）"，
  sha256 与 `sun2.png` **逐字节相同**（★ 别再当新参考存第二份）。这一张是治"像种草一样"的参照：
 **大尺度结构**（成片的**大弧**、弧腿之间的**暗腔洞**、活动区的**亮核**、很软的日缘） |
