# 35 · 第 12 轮：颜色分层（用户："颜色也丰富一点吧，看看参考图，很微妙的"）

## 一、先把参考图的颜色结构读出来

拿 `art/reference/gasgiant-saturn.png` 逐块看：

| 区域 | 颜色 |
|---|---|
| 北半球（受光） | **奶黄/奶油**，中纬度几条带偏**琥珀/鲑**（暖） |
| 赤道带 | 更亮、更**偏白** |
| 环影以南那一大片 | 明显偏**青灰/石板**（冷）—— 这一片同时也在环的影里 |
| 北极（上端） | 淡**蓝白** |
| 受光边缘（左） | 一圈暖黄的散射 |
| 背光那半边 | 深蓝灰、近黑但**不发黑** |
| 环影那条 | 暗灰褐 |
| 云带色差本身 | **很小** —— 就几个百分点，不是"加饱和" |

⇒ 关键认识：参考图的"丰富"是**低饱和下的色相分层**（暖带 / 奶油区 / 冷极），不是更鲜艳。

## 二、加了哪三档（都在材料色那一支上乘）

`art/shaders/gasgiant.wgsl` 新加三栏，`gas = albedo × 带区色 × 极区色 × 透过率`：

| 栏 | 语义 |
|---|---|
| `belt_tint` | **暗带**那一端的乘色（暖：R↑ B↓） |
| `zone_tint` | **亮区**那一端的乘色（奶白偏中性）；两者以 `band_shaped` 混合 |
| `polar_tint` | **极区**乘色（冷）—— 参考图两端偏冷、赤道最暖 |

⚠ 三档都乘在 `gas` 上（"这柱气体自己是什么颜色"），不是乘在光上 —— 与直射/边缘/霾那几支分开。

## 三、⚠ 两处走错又量回来的事（都写下来）

### 1. 第一版把"冷"写成**某一半球**（`-纬度`）⇒ 画面上几乎看不见

`hemi_tint = [0.45, 0.60, 1.45]`（夸张档）渲染出来**几乎没有变化**（`target/probe-gg-hemi-exaggerated.png`）——
因为**这个机位下可见盘面以另一半球为主**，那半球根本不在画面上。
A/B 读数也只有 `(B−R) +0.24`（南半球的屏幕采样区其实贴近赤道：**屏幕下方 ≠ 行星南纬**，
自转轴是倾斜的）。⇒ 参考图那种"冷"本来就是**按 `|纬度|`** 来的（两端冷、中间暖），
改成 `polar_tint` + `smoothstep(0.45, 1.0, |纬度|)` 之后，同一张夸张档**清楚地落在北极端**
（`target/probe-gg-polar-exaggerated.png` 顶上那片蓝白）⇒ 机制证实。

### 2. 第二版颜色**过于橙**（比参考图饱和）

`belt_tint = [1.030, 0.955, 0.880]` 出来的暗带偏橙；参考图的暗带是**灰褐**。
收敛到 `[1.012, 0.968, 0.912]`，并把 `albedo` 从 `[0.870, 0.800, 0.660]` 调成
`[0.878, 0.826, 0.706]`（**降饱和**去追参考图那份克制）。

## 四、读数（同机位，屏幕圆盘内 30 万像素）

| 版本 | 北 R/G/B | 南 R/G/B | 北 B/R | 南/北亮度 |
|---|---|---|---|---|
| 加颜色之前（`probe-gg-aperiodic`） | 158.1 / 143.1 / 109.7 | 125.5 / 115.6 / 95.2 | 0.694 | 0.808 |
| 第一版（偏橙） | 158.8 / 141.9 / 107.2 | 125.8 / 114.8 / 93.6 | 0.675 | 0.808 |
| **现在**（`probe-gg-color2`） | 160.4 / 146.0 / 112.9 | 125.9 / 116.3 / 96.1 | **0.704** | 0.797 |

⇒ 北半球蓝/红比从 0.694 抬到 **0.704**（**降饱和**、往奶白走），暗带与亮区的色相差在画面上可见
（带偏琥珀、区偏奶白）；极区冷档用**夸张档**证实落点正确，常态档是 `[0.930, 0.962, 1.040]`。
