# 太空沙盘游戏《行星X》设计

回合制，回合时间单位月，每回合每个势力可以下达任意数量指令

## 实体

- 天体
  - 定居点：可以容纳一个城市
- 城市：可以被势力控制
  - 建筑：任意数量
    - 居住区
    - 开采区
    - 建造区
- 势力
  - 互相外交
- 飞船
  - 必须被势力控制
  - 飞船之间可以互相攻击
  - 飞船可以轰炸定居点

## 属性

- 天体
  - 定居点
    - 总面积
    - 生态容量（人口/面积）
    - 建设速度修正（面积/时间）
    - 建设资源修正（面积/资源）
    - 资源
      - 类型
      - 面积：限制开采区面积
  - 轨道（2D，圆心为太阳）
    - 近日点距离
    - 远日点距离
    - 远日点方向（单位向量）
    - 公转周期
    - 当前位置
- 城市
  - 人口：限制生产效率
  - 区域
    - 开采区
      - 资源类型
      - 面积
    - 建造区：建造飞船
      - 面积
  - 建筑
    - 护甲
    - 面积
    - 建设速度
    - 建设各类资源
    - 员工需求（人口/面积）
    - 幸福度/生产效率修正
- 飞船
  - 船体
  - 船体再生（%）
  - 护甲修正（%）
  - 护盾修正（%）
  - 点防御修正（%）
  - 护盾再生修正（%）
  - 速度上限修正（%）
  - 加速度修正（%）
  - 伤害修正（%）
  - 攻击距离（%）
  - 建造各类资源
  - 槽位：装配的组件数上限
- 组件：
  - 武器：至少1个
    - 伤害
    - 伤害类型
    - 射程
    - 追踪
  - 推进：至少1个
    - 速度上限
    - 加速度
  - 护盾
  - 护甲
  - 点防御
  - 辅助：再生

## 控制属性

- 势力
  - 各类资源投资预算（资源/时间）
  - 各类资源建造预算
- 建造区
  - 建造投资权重
  - 建造飞船类型
- 建筑
  - 建设投资权重
- 飞船
  - 行为（枚举）
    - 目标地点
    - 目标飞船
      - 是否攻击
    - 目标城市
      - 是否轰炸
    - 停泊轨道
    - 待命
