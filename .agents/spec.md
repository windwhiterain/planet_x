# 太空沙盘游戏《行星X》设计

回合制，回合时间单位月，每回合每个势力可以下达任意数量指令

## 实体

- 天体
  - 定居点：可以容纳一个城市
- 城市：可以被势力控制
  - 建筑：任意数量
    - 居住区
    - 开采区
    - 建造区
- 势力
  - 互相外交
- 飞船
  - 必须被势力控制
  - 飞船之间可以互相攻击
  - 飞船可以宏站定居点

## 属性

- 天体
  - 定居点
    - 总面积
    - 生态容量（人口/面积）
    - 建设速度修正（面积/时间）
    - 建设资源修正（面积/资源）
    - 资源
      - 类型
      - 面积：限制开采区面积
  - 轨道（2D，圆心为太阳）
    - 近日点距离
    - 远日点距离
    - 远日点方向（单位向量）
    - 公转周期
    - 当前位置
- 城市
  - 人口：限制生产效率
  - 区域
    - 开采区
      - 资源类型
      - 面积
    - 建造区：建造飞船
      - 面积
  - 建筑
    - 护甲
    - 面积
    - 建设速度
    - 建设各类资源
    - 员工需求（人口/面积）
    - 幸福度/生产效率修正
- 飞船
  - 船体
  - 船体再生（%）
  - 护甲修正（%）
  - 护盾修正（%）
  - 护盾再生修正（%）
  - 速度修正（%）
  - 加速度修正（%）
  - 伤害修正（%）
  - 攻击距离（%）
  - 建造各类资源

## 控制属性

- 势力
  - 各类资源投资预算（资源/时间）
  - 各类资源建造预算
- 建造区
  - 建造投资权重
  - 建造飞船类型
- 建筑
  - 建设投资权重
- 飞船
  - 行为（枚举）
    - 目标地点
    - 目标飞船
      - 是否攻击
    - 目标城市
      - 是否轰炸
    - 停泊轨道
    - 待命

- 飞船（舰级 = 平台修正器）
  - 属性分两类：
    - 直接：船体（模块不能改）、船体再生（%）
    - 修正（%）：护甲修正、护盾修正、护盾再生修正、速度修正、加速度修正、伤害修正、攻击距离修正
  - 槽位：可同时装配的组件数
  - 组件：
    - 武器：伤害/伤害类型/射程/追踪/对盾倍率/对甲倍率（伤害来源）
    - 推进：速度/加速度（机动来源）——**必须至少一件**，否则跑不动
    - 护盾：吸收池/再生（可选，吸收伤害）
    - 护甲：硬度数值（可选，反比例让船体变硬）
    - 点防御：拦截强度（可选，线性扣减导弹）
    - 辅助：护盾再生/再生
  - 要求：每舰**至少一件武器 + 至少一件推进**（火力与机动都来自模块）；护盾/护甲/点防/辅助可选
- 护卫舰（轻装游骑）
  - 直接船体：低
  - 速度修正：高，加速度修正：高（招牌：极速）
  - 伤害修正：低，攻击距离修正：低
  - 槽位：2
- 驱逐舰（再生磨王）
  - 直接船体：中
  - 护盾再生修正：高（招牌：持久磨）
  - 伤害修正：低，攻击距离修正：中
  - 槽位：2
- 巡洋舰（重型装甲）
  - 直接船体：高（招牌：扛）
  - 护甲修正：高，护盾修正：高
  - 速度修正：低
  - 槽位：3
- 航空母舰（超远程压制）
  - 直接船体：低
  - 攻击距离修正：高（招牌：远）
  - 伤害修正：低，速度修正：低
  - 槽位：3
- 战列舰（一锤定音）
  - 直接船体：低（略抬以可抗一轮齐射）
  - 伤害修正：高（招牌：重火力）
  - 槽位：4
