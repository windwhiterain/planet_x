# 太空沙盘游戏《行星X》设计

回合制，回合时间单位月，每回合每个势力可以下达任意数量指令

## 实体

- 天体
  - 定居点：可以容纳一个城市
- 城市：可以被势力控制
  - 建筑：任意数量
    - 居住点
    - 开采点
    - 建造点
- 势力
  - 互相外交
- 飞船
  - 必须被势力控制
  - 飞船之间可以互相攻击
  - 飞船可以宏站定居点

## 属性

- 天体
  - 定居点
    - 总面积
    - 生态容量（人口/面积）
    - 建设速度修正（面积/时间）
    - 建设资源修正（面积/资源）
    - 资源
      - 类型
      - 面积：限制开采点面积
  - 轨道（2D，圆心为太阳）
    - 近日点距离
    - 远日点距离
    - 远日点方向（单位向量）
    - 公转周期
    - 当前位置
- 城市
  - 人口：限制生产效率
  - 生产点
    - 开采点
      - 资源类型
      - 面积
    - 建造点：建造飞船
      - 面积
      - 建造投资权重：指令控制
  - 建筑
    - 面积
    - 建设速度
    - 建设各类资源
    - 员工需求（人口/面积）
    - 幸福度/生产效率修正
    - 建设投资权重：指令控制

- 势力
  - 各类资源预算（资源/时间）：指令控制，决定拿出多少资源用于投资
