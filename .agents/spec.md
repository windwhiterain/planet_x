# 太空沙盘游戏《行星X》设计

回合制，回合时间单位月，每回合每个势力可以下达任意数量指令

## 实体

- 天体
  - 定居点：可以容纳一个城市
- 城市：可以被势力控制
  - 建筑：任意数量
    - 居住区
    - 开采区
    - 建造区
- 势力
  - 互相外交
- 飞船
  - 必须被势力控制
  - 飞船之间可以互相攻击
  - 飞船可以宏站定居点

## 舰船定制与战斗（伤害类型 × 防御 / 规避 / 点防）

飞船不只是「一个 class + 一个标量攻击力」，而是**可定制的作战平台**。定制不是把属性
加个数字，而是改变**打法**——组件引入不同的武器/防御系统，使资源优势真正转化为战场
优势（数据驱动、确定性、无未播种 RNG）。

### 战斗模型（`sim::fire` / `sim::bombard_city`）

- 每舰有一组**武器系统**（舰级炮台 + 装配的武器组件），逐一按自身 `range`（交战距离）
  决定是否参与齐射——**射程是真实的战位选择**，不是加分项。
- 每件武器有原生**伤害类型** `damage_type`（`kinetic` / `plasma` / `missile`）和
  **对护盾 / 对船体**倍率（`shield_mult` / `hull_mult`）：
  - kinetic：对甲强、对盾弱（拆船体装甲）。
  - plasma：对盾强、射程远。
  - missile：超远射程、制导（对高速目标规避弱），但会被**点防御**拦截。
- **规避（确定性）**：命中率 = `1 - evasion`，`evasion = (target_speed/(tracking+target_speed))×k`。
  高速目标对低追踪武器的规避强——**推进组件 = 生存与抢先战位**。无 RNG（以「伤害折减」
  而非「命中/未命中」实现，保持确定性）。
- **双池防御**：能量**护盾**（`shield`/`shield_max`）优先吸收、每回合 `shield_regen`
  再生；**船体**（`hull`/`hull_max`）是装甲本体。护盾满时按 `shield_soak` 削弱穿透的
  船体伤害——所以护盾组件是「挡第一波」的，装甲是「扛持久」的。
- **轰炸城市**用「每件武器 × 对甲倍率」的总齐射（城市是静止的大型装甲目标，无护盾、
  不规避）。
- 本土防御/MOND 仍按原逻辑削减最终伤害。

### 舰船定制组件（`components` 配置表 + `Ship::components`）

- 每个舰级有 `slots`（组件槽位数）：护卫 1 / 驱逐 2 / 巡洋 3 / 航母 3 / 战列 4。
- 造舰出厂时，模拟用 **`choose_loadout`（确定性）** 按该势力的**资源优势**装配组件：
  - 组件成本拉在稀有矿物上（铀/氦-3/铂/金/钍/氢），**买得起且资源丰沛**的分高，
    买不起的直接不装——所以掌控稀有矿的势力能造出更锋利的船。
  - 选装是**资源→战斗力**的链接：铀→磁轨/重炮拆甲；金/铂→护盾+等离子；氦-3/氢→
    高速导弹袭扰；铁/碳→用入门动能+装甲。
  - 纯确定性（无 RNG，分数 = 库存价值的函数，平局按组件 id 排序），长局可复现。
- 组件成本在出厂时从势力库存一次性扣除，`upkeep` 随组件上升——强组件难养，抑制无脑堆。
- agent 直读：每舰输出带 `components` 与 effective 面板（`hull`/`hull_max`/`shield`/
  `shield_max`/`attack`/`range`/`speed`/`hull_regen`/`upkeep`）；`meta` 暴露全部组件表。

## 剧情（编年史）

- 配置文件 `story` 表定义一条**数据驱动的叙事弧**，每条剧情事件有：
  - `id`：稳定标识
  - `title` / `body`：标题与叙事正文
  - `participants`：参与方可读名。事件型触发会把本回合事件的**具体对象**追加进来
    （谁与谁开战 / 哪座城被夷平 / 谁建立了殖民地），使编年史自描述。
  - `trigger`：触发条件
    - `RoundAt(round)`：到达某回合（时间线节拍）
    - `FirstWar`：世界第一次出现交战
    - `FirstRaze`：第一次有城市被夷平
    - `FirstColony`：第一次建立/再殖民城市
    - `WarBetween(a,b)`：指定两势力第一次交战
    - `FactionAtWar(faction)`：指定势力第一次与任何人交战
    - `RelationBelow(a,b,value)`：a 对 b 关系跌破某值
  - `effects`：可选小幅、确定性机械后果
    - `Relations(a,b,delta)` 关系
    - `GrantResources(faction,resource,amount)` 资源
    - `GrantShip(faction,class,body)` 在某天体附近为某势力「出厂」一艘舰（id 连续、确定性）
- 模拟每回合评估触发（`sim::step_story`），事件型触发恰好落在对应历史事件发生的回合。
- 触发后写入 `State::chronicle` 编年史（可查询整段弧），并作为 `events` 里的 `story` 事件出现在本回合流水。
- **确定性**：剧情全无 RNG，同一种子触发完全一致；checkpoint 续玩仍复现。
- 外交跃迁（开战 `war_started` / 停战 `war_ended`）作为事件暴露。

## 复现与续玩

- 同一种子 + 相同配置 + 相同回合数 → 输出逐字节一致。
- `--save` / `save` 写出 checkpoint（State + PRNG 位置）；`--start` / `load` 恢复，续玩复现后续回合（剧情编年史一并保存/恢复）。

## 长期可玩性（上千回合依然有意义、不崩坏）

为使世界在上千回合后仍是**多方参与**的博弈，而不是收敛成「少数永久霸权 + 一堆永久
旁观者」或经济无限膨胀/塌缩，模拟叠加以下机制（全部确定性、数据驱动）：

### 光速治理（`governance` 配置 + `State::control` 的 `loyalty_budget` 叶子）

- 每个势力有 `capital_body`（首都天体）。一座城离首都越远，治理开销越高、忠诚度越低。
  - 治理开销 = `admin_base + admin_per_au × max(0, dist−admin_range)`（市场价值/回合/城）。
  - 忠诚度目标 = `clamp(1 − loyalty_distance × max(0, dist−loyalty_range), 0, 1)`。
- **人口越多、管理能力越分散**：势力总人口超过 `population_capacity` 即进入「超载」，
  超载放大上述距离惩罚（`scale = 1 + overload`）——距离与人口叠加。
- 势力每回合用库存（按价值加权）支付治理开销；付得起（覆盖率≈1）时忠诚度向目标恢复，
  付不起时按欠费比例下降，跌破 `loyalty_revolt` 即爆发**离心叛乱**（`Revolt` 事件，
  城市被夷平为空白、可再殖民）。
- **娱乐/福利预算**：每座城是一个 `loyalty_budget` 可控叶子（`Control<f64>`，市场价值/回合）。
  投入提升忠诚度目标（`+paid/entertainment_cost`），对冲距离/人口带来的离心倾向——即
  「枪支与黄油」的现实权衡：花钱安抚居民，就少了建设与造舰的预算。

### 本土防御 / 首都即强弩（每势力 `home_radius` 等字段）

- 每座城/舰在其势力首都 `home_radius` AU 内获得本土防御：敌方对其伤害 ×
  `home_attack_mult`（<1 = 削弱入侵者），本方舰获得额外 `home_regen_bonus` 护甲再生。
- 每势力可设不同数值；超大国大规模扩张到别人家里会付出代价，自然遏制一家独大。

### MOND / 柯伊伯引力异常（`mond` 配置）

- 距太阳超过 `mond.radius` 的深空进入「异常区」。真实引力按 MOND（修正牛顿动力学）
  偏离标准牛顿假定，**没有掌握 MOND 修正引力的势力**（即除 `mond.masters` 之外的所有
  势力）在异常区内轨道计算错误——指令坐标与实际到达坐标产生**切向偏移**
  （`mond.drift_per_au × 超出半径的深度`），无法精确轰炸/殖民/停靠深处目标。
- cult（行星X崇拜教，`masters=[8]`）「掌握了正确的牛顿修正引力」，在异常区内指哪打哪。
  这让它偏僻的柯伊伯带圣所成为天然堡垒：围攻者在那里「迷航」，而 cult 能自保。

### 反僵尸重建（`sim::step_resurgence`）

- 一支势力若在某回合结束时**既无舰又无活城**（被彻底消灭、无从再殖民/重建的下限），
  会在它仍拥有残骸足迹的定居点（或全系统最低 id 的空白定居点，作为难民避风港）
  重新站稳脚跟：重建一座新城并出厂一艘廉价种子舰。这保证了没有势力会**永久**变成
  旁观者——被夷平到零也能以重建身份回到游戏。

### 合纵连横 / 均势外交（`balance` 配置 + `sim::step_balance_of_power`）

- 每个势力的综合实力占比按 `power_city_weight×城市份额 + power_fleet_weight×舰队份额`
  加权归一（城市份额 = 活城数/总活城数，舰队份额 = 舰艇引擎数值/总引擎数值）。
- 当某势力的实力占比达到 `hegemon_power`（如 0.30）时被判定为**霸权**；此时其余较弱
  势力被「共同威胁」推向彼此，并针对霸权抱团（合纵连横）：
  - **合纵**：弱者-弱者之间的关系向 `coalition_affinity` 靠拢（`coalition_rate`/回合）——
    疏远的弱国结成反制联盟。
  - **均势 / 遏制**：弱者对霸权的关系被下压到 `hegemon_affinity`（`hegemon_rate`/回合），
    但**只在它比该目标更暖时才下压**，绝不无脑推到交战阈值以下——冷对抗而非热情，
    霸权被孤立、被提防，却不一定立刻被开战。
  - **集体安全**：当霸权对任一弱者开战（本回合新跨入交战阈值）时，其余尚未交战的弱者
    对霸权的关系骤降 `collective_defense_delta`——「攻其一方 = 与全体为敌」，弱者联盟
    群起而攻之。此时结盟势力的舰只**优先集火该霸权**（`sim::coalition_war_focus` 接
    `nearest_enemy_ship`/`pick_target`），使集体防御真的打得赢（不再是各自就近乱打）。
  - **经济制裁**：只要某势力**已称霸（实力占比达标）且至少有一个弱者倒向联盟**（关系 ≤
    `coalition_estrange`），就被多国封锁——不必等联盟完全成形（`sim::sanctioned_hegemon`）。
    被封锁的霸权的自动市场交易额度按 `sanction_trade_mult`（如 0.3）缩水——它难以再靠
    市场兑换短缺矿物（铀/氦-3/铂），产业受抑，形成「多国资源封锁 & 资源失衡」；同时其
    **维持帝国（行政 + 娱乐）的成本按 `sanction_cost_mult`（如 1.45）放大**——被孤立的
    大国要花更多资源养边地、治安成本上升，远端/边缘殖民地更难养、更易离心叛乱，体量
    自然回落。
- 事件：联盟成立/解体记为 `CoalitionFormed`/`CoalitionEnded`（`members` 为成员）。当前
  格局（`hegemon`/`members`/`power_share`）暴露在 agent 的每回合 `coalition` 字段与
  `meta` 的 `balance` 配置里，供 AI 读出「谁在出头、谁在联合制衡」；每座城还带 `loyalty` 与 `gov_distance`（到首都距离），
让 AI 一眼看出哪些城在失稳边缘、好据此投娱乐预算。
- **确定性**：全套无 RNG、数据驱动；同一种子触发完全一致。`hegemon_power > 1` 即关闭。
- **目的**：给「一家独大」一个众矢之的——领土/军事的联合制衡 + 经济的资源封锁，使上
  千回合后的世界保持多方参与（不统一、最强势力会轮换），而非收敛成少数永久霸权。
