# 太空沙盘游戏《行星X》设计

回合制，回合时间单位月，每回合每个势力可以下达任意数量指令

## 实体

- 天体
  - 定居点：可以容纳一个城市
- 城市：可以被势力控制
  - 建筑：任意数量
    - 居住区
    - 开采区
    - 建造区
- 势力
  - 互相外交
- 舰船
  - 必须被势力控制
  - 舰船之间可以互相攻击
  - 舰船可以轰炸定居点

## 属性

- 势力
  - 各类思潮偏向
    - 和平<->军国
      - 变化因素：战争失利<->战争得利
    - 科学<->技术
      - 变化因素：飞船在MOND区域<->开采MOND区域资源
    - 人民<->精英
      - 变化因素：经济坏<->经济好
    - 自然<->殖民
      - 变化因素：人均面积高<->人均面积低
- 天体
  - 定居点
    - 总面积
    - 生态容量（人口/面积）
    - 建设速度修正（面积/时间）
    - 建设资源修正（面积/资源）
    - 资源
      - 类型
      - 面积：限制开采区面积
  - 轨道（2D，圆心为太阳）
    - 近日点距离
    - 远日点距离
    - 远日点方向（单位向量）
    - 公转周期
- 城市
  - 人口：限制生产效率
  - 区域
    - 开采区
      - 资源类型
      - 面积
    - 建造区：建造舰船
      - 面积
  - 建筑
    - 护甲：反比例函数减伤
    - 面积
    - 建设速度
    - 建设各类资源
    - 员工需求（人口/面积）
    - 幸福度/生产效率修正
- 舰船
  - 船体
  - 护甲修正（%）
  - 护盾修正（%）
  - 点防御修正（%）
  - 船体再生速度（%/时间）
  - 护盾再生速度修正（%）
  - 速度上限修正（%）
  - 加速度修正（%）
  - 伤害修正（%）
  - 攻击距离（%）
  - 建造各类资源
  - 槽位：装配的组件数上限
- 组件：
  - 武器：至少1个，独立索敌单位
    - 射速（发/时间）：每一发可独立索敌，单回合内多发可以火力分配
    - 伤害
    - 伤害类型
    - 射程
    - 点防御：线性减伤
  - 推进：至少1个
    - 速度上限
    - 加速度
  - 护盾：伤害吸收池
  - 护盾再生速度：%/时间
  - 护甲：反比例函数减伤

## 控制属性

- 势力
  - 各类资源投资预算（资源/时间）
  - 各类资源建造预算
  - 首都
    - 首都会给予全国忠诚度修正，与首都人口占比正相关
    - 首都变化会降低全国忠诚度，与首都人口占比正相关
- 建造区
  - 建造投资权重
  - 建造舰船类型
- 建筑
  - 建设投资权重
- 舰船
  - 警惕<->激进：风筝<->贴脸
  - 行为风格：自动控制行为
    - 理智<->热血：欺软怕硬（倾向靠近威慑低于自己的）<->飞蛾扑火（倾向靠近威慑高于自己的）
    - 护航<->独狼
  - 行为（枚举）：攻击不需要行为，范围内有敌人就会攻击
    - 目标地点
    - 跟随舰船
    - 停泊城市
    - 停泊天体
    - 殖民
    - 静止
- 组件/武器
  - 火力分配：单一目标<->雨露均沾（根据攻击历史）

## 导出属性

- 势力
  - 实力
- 舰船
  - 威慑：综合战力，附近的同势力舰船战力会互相叠加
- 天体
  - 当前位置
