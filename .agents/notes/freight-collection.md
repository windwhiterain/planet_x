# 集货腿与运输承包市场（首都 = 集散地）

> 状态 `[ ]`（**设计，待裁决 D1–D8**，未实现） ｜ 索引：[notes.md](../notes.md) ｜
> 关联：[贸易与制裁](trade-and-sanctions.md)（§「运费 + MOND 承运」是本文的前半段）、
> [经济深度](economy-depth.md)、[治理与忠诚度](governance-loyalty.md)、[均势](balance-of-power.md)

本文接着 `trade-and-sanctions.md` 的 M6 走：那边已经把**势力间**的运输做成了「资本挂价税」
（首都↔首都距离 + 异常带浸入深度 + MOND 承运人）。用户给的新前提是——

> **首都必须是势力货物的集散地，因此势力间的贸易路线确定。**

这一句把现有实现从「漏洞」升级成「公理」：首都↔首都就是**唯一**的对外路线，不用改。
于是缺口只剩两条，本文要解决的就是这两条：

1. **A：集货腿** —— 各天体（产地/消费地）到自己首都的运输路线；
2. **B：运输承包的市场系统** —— 谁替你运、按什么价、风险归谁。

---

## 0. 一句话设计

**货物分两段走**：产地 →（A 集货腿）→ 本国首都 →（现有首都↔首都）→ 对方首都 →（A）→ 对方产地。
A 段与 B 段（现有海运段）**用同一套闭式**（`route_depth` / `freight_rate` / `mond_loss`），
区别只在**谁付**：自运则烧掉（sink），承包则付给承运人。
承运人不再由 config 写死，而是一个**有运力的供给侧**在挂价。

## 1. 现状（要接上的那一半）

`src/sim.rs::step_market`（L900–1107）：

```rust
let anchor_b = trade_anchor(state, &buyer);      // L2242：首都天体位置（无城→第一艘活舰→原点）
let anchor_s = trade_anchor(state, &seller);
let depth    = route_depth(config, anchor_b, anchor_s);   // L2260：闭式，无 RNG
let freight_rate = m.freight_per_au * dist_au * (1.0 + m.mond_freight_mult * (depth/(depth+1)));
let p_eff = p * (relation_price_mult + freight_rate);
// 丢货：买卖任一方是 MOND master 则 reliable（不丢）
let loss = if depth > 0.0 && !reliable { (m.mond_loss_per_au*depth).clamp(0.0, m.mond_loss_cap) } else { 0.0 };
// 承运人 = masters 里第一个「既不是买方也不是卖方」且还存在的势力；carrier_share=1.0
let carrier = config.mond.masters.iter().find(|x| *x != &buyer && *x != &seller && exists);
```

实测（400 回合，seed 7 / 42）：**只有行星X崇拜教**有承运收入（**953.0 / 155.0**），
其余八家全 0；它自己付的运费（248.1 / 82.7）因「唯一 master 即当事方 → carrier=None」**整笔烧掉**。

问题清单（详见对话）：运费挂在**政府的座位**上而非货上；**没有任何船参与运输**；
`carrier` 与舰级 `carrier`（航母）重名；**深空运输联盟**——名字就是干这个的——`carrier_income = 0`。

## 3. 设计 A：集货腿（产地 → 首都）

**按「产出流」收费，不按库存。** `Faction::resources` 是**全局池**，没有分城库存——
引入分城库存是大改，且与「首都即集散地」的公理重复。所以：

> 产出在产地算出、写进势力池的那一刻，就是「运抵首都」的那一刻，集货成本在这里扣。

钩子就在 `step_production`（L689–703）的三行：

```rust
let output = effective * labor * spec.productivity * config.economy.production_rate;
*flow.city_production... += output;
*flow.faction_production... += output;
if let Some(f) = state.faction_mut(&faction_id) { *f.resources.entry(rt).or_insert(0.0) += output; }  // ← 这里
```

改成 `output × (1 − 集货损耗)` 入库，并在 flow 里记一份 `collection_loss`。

**两段成本，同一套闭式**（`dist = |产地 − 首都|`、`depth = route_depth(产地, 首都)`）：

1. **物理损耗**（谁都躲不掉，包括自运）：`loss = clamp(mond_loss_per_au×depth, 0, cap)`
   —— 直接复用现有 MOND 丢货语义（非 master 才丢，master 免）。**加一条基础损耗**
   `base_transit_loss_per_au × dist`（建议 0.002/AU：30 AU → 6%），否则「近处运也会零星丢」不成立。
2. **运费**（服务费）：`freight = 货值 × freight_per_au × dist × (1 + mond_extra)`
   —— 自己运 → **烧掉**（sink，没有对手方）；承包给别人 → 付给承运人（见 B）。

**无舰势力**：晚期那 6 家 0 舰的势力，**运不出来**。裁决点 D8：是「只能承包，承包不到就烂在产地」，
还是「照运但损耗加倍」（更温和）。

## 4. 设计 B：运输承包的市场系统

现状不是市场，是**收费站**（承运人由 `config.mond.masters` 写死，`carrier_share=1.0` 全拿）。
要成为市场，需要三样东西：

### B1 供给侧：运力从哪来

`Ship` **完全没有货舱字段**（`src/model/ship.rs` L50–83），舰级表也没有 `cargo`。三个选项：

- **(a) 舰级加 `cargo`（推荐）**：`ships:` 表每级加一个货舱值（护卫 2 / 驱逐 4 / 巡洋 6 /
  **航母 20** / 战列 6），运力 = Σ 活舰 `cargo × (hull/hull_max)`。航母（现在只有战斗意义）
  变成**专业货舰**，`slots: 3` 与 `build_cost` 的高稀有矿成本正好是「运输业要重资产」的体现。
  数据驱动、不新增舰级、不给战斗面板添乱。
- (b) 新增舰级「货船」：更直白，但要在 5 级战斗舰体系外再造一类，且它的战斗面板（现在舰级属性
  全是战斗导向）没有意义。
- (c) 不设运力上限：**市场退化成「谁最便宜谁全包」**，等于没有市场。排除。

### B2 定价：挂价簿（推荐）

承运人像商品一样挂单，与现有 `Offer` 同构：

```rust
pub struct FreightOffer { carrier: FactionId, from: BodyId, to: BodyId, rate: f64, capacity_left: f64 }
```

- `rate` 量纲与 `freight_per_au` 同（每 AU × 每单位货值）。
- 承运人的**成本**就是同一套闭式（它自己的距离/深度/损耗）→ 挂价 = 成本 × `(1 + carrier_margin)`。
- 托运方按 **可靠优先 → 价低者先 → 名字兜底** 确定性选择（与现有撮合同构，不掷骰）。
- 备选：(b) 承运人成本加成自动定价（简单，但没博弈、不算市场）；(c) 竞价/拍卖（复杂，确定性难保）。

### B3 结算与截断

仍是**实物**（无货币）：承运人收到 `货值 × rate` 的货，从托运人的挂单里取（`pay_with_surplus`）。
**必须明确截断**：承运人收款入其**自己的首都池**，不再对它收二次集货费——否则递归。

### B4 资质与禁运

- **谁都能承运**（有舰即有运力），但**只有 MOND master 在异常带内可靠**
  （现有 `reliable = is_master(buyer) || is_master(seller)` 的承运人版）。
- 非 master 承运人要自己承担丢货 → 它必须把风险计价进 `rate` → **市场自己得出「带内垄断」的结论**
  （这正是我们想要的：不是配置写死崇拜教垄断，而是它的成本结构导致它报价最低）。
- **禁运延伸到「不给你运货」**（D7）：`trade_blocked` 现在只挡买卖，应同样挡承包——
  「封锁航线」比「不卖矿」更狠，让制裁真的有牙齿。

`carrier_margin`、`self_carry_discount`（自运比承包便宜多少）、`no_ship_penalty`；
`model::freight`（`FreightOffer` / `FreightState`）或并入 `model::market`；
`RoundFlow` 加 `collection_loss`；`FactionMetrics` 加 `freight_income`（`carrier_income` 扩展）、
`carried_value`、`capacity_used`。

**确定性**：全部闭式 + 确定性排序，**不消费 `Prng` 流**（与现有市场一致）。
**Schema**：新字段带 `#[serde(default)]` + `SCHEMA_VERSION` +1（现 5 → 6），`migrate` 接受旧值。

  （≥2 家承运人有收入）；0 舰势力仍能存活但有代价。

## 8. 预期影响与风险

**预期**：
- 深空开采第一次有代价 → AI 选址激励改变（可能**抑制**观测到的「世界重心外移」，待测）；
- 运输业成为一门真生意，**深空运输联盟**（现在 `carrier_income=0`）有活干；
- 崇拜教从「配置写死的收费站」变成「成本结构导致的自然垄断」——同样的结果，但机制上是挣来的；
- 迁都有了经济含义。

**风险**：
- **崇拜教优势可能被放大**：集货损耗对 master 豁免，而它的圣所在带内 → 它是唯一能廉价开采柯伊伯带的
  势力。这符合设定（「偏僻圣所是天然堡垒」），但需要实测它会不会滚成不可逆霸权。
- **晚期全员带内**：r400 实测多数幸存者首都在带内（星系矿业@冥王星、美国@卡戎、
  联合国/深空运输联盟@海王星）→ 每吨货都要穿异常带 → 全体产出被扣 ~2–10%。这是**后果**不是 bug，
  但需要看它会不会把晚期经济压死。
- **叠加风险**：运费已叠加在关系加价之上（买敌人的货 2.5×），再加集货腿 → 深空势力可能**买不起也运不起**。
  需要实测「末端势力是否还能重建」。
- 递归/双重计价（承运人的收款是否再走集货腿）必须显式截断，否则数值会悄悄翻倍。
