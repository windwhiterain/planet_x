## 0. 一句话

现在的「星际市场」**没有卖家、没有仓、没有价格**——它是一台以常数价格无限供货的自动贩卖机，
所以「缺某种矿」在游戏里**不可能**产生高价，也**不可能**出现「不卖给你」。要让它真实有力，
得把它改成一个**有挂单、有仓、有价、可禁运**的交换所，并让**最稀缺的矿恰好就是最强的军备材料**
（这一条数据已经在游戏里了，只是没有任何机制去咬它）。

### 实现要点（照做即可，别再重造）

* **价格发现**：`mult = (coverage_rounds / 覆盖回合数)^price_alpha`，覆盖回合数 = 世界总库存 ÷
  **实测消费率**（由「上回合市场时刻库存 + 本回合产出 − 本回合市场时刻库存」量出来——
  不猜需求）。稀缺顶到 `price_ceiling`(8×)，过剩折到 `price_floor`(0.4×)；需求 ≤ `demand_min`
  的资源按基价（否则没人用的矿会被永久顶成天价）。
* **挂单**：`exportable = 库存 − max(自己需要的 working_buffer, 库存 × reserve_fraction)`。
  挂单**记名卖家**、按 `(卖家, 资源)` 记账——**禁运的货绝不能进公共池**，否则经市场转手、
  封锁形同虚设。
* **结算**：买方按**购买力**（自己挂单簿上的实物价值）降序入场（「钱多的人先买」，确定性），
  想买的资源**越贵越先买**，从别人的挂单里取，**卖光就买不到**。付款 = 把自己可出口的实物
  交割给卖家 + 按 `spread` 烧掉一笔（真实价值 sink）。
* **禁运** `sim::trade_blocked`（三档、对称）：① 交战；② 已倒向联盟的弱者 ↔ 被锁定的霸权；
  ③ 关系 ≤ `embargo_relation`(-14)。`trade_block_cause` 给出原因（对账用）。
* **关系即价格** `relation_price_mult`：对敌封顶 `1+hostile_price_markup`，对友打折
  `friendly_price_discount`。同一个矿，向敌人买贵得多。
* **组件硬门槛**（`autocontrol::shipbuilding::choose_loadout`）：**武器**只装付得起的
  （买不起就退回廉价档，甚至空着）；**推进器是平台**（没有推进器的舰下不了水，付不起也装）。
  这条区分是实测逼出来的：把推进也硬门槛化后 4 个单测直接红——船动不了，战争随之消失。

## 0.2 实测（seed 7，400 回合，默认配置）

* 价格真的会动：`氦-3/金/氢` 断供时打到 **8.00×**，`铁` 在 r120 打到 **8.00×**，
  `碳/硅/水冰` 过剩时折到 **0.5–0.7×**。
* 供给是有限实数：r120 挂单 `碳=222 硅=127 水冰=103`；累计成交额 19924（seed 7）。
* 净进口分化出真实贸易国：`中国 +2530`、`星系矿业 −1728`、`联合国 −1928`（净出口国）。

* 稀缺咬到战斗力（A/B 市场额度 0 vs 80）：关市时防御几乎只有装甲夹层（铁/碳），
  开市后**复合装甲(硅/钍)/护盾(铂/氦-3)/近防(金/硅)** 成批出现。

## 7. 删掉 `step_resurgence`（D5）：实测、代价与机制改判

`step_resurgence` 是**反僵尸重建**：一支势力一旦「无舰又无活城」，就**凭空**在自己的残骸足迹 /
任何空白城 / 任何未占据定居点上重新立起一座城（甚至夺取城数最多者的活城），还白送一艘种子舰。

**已删除。** 现在世界只有一条重建路径，且它是物理的：
**造殖民舰 → 开到空白定居点 → `colonize` 复垦**（`sim::colonize` 里有两条 debug 断言：
必须有一艘**此刻就在场的活舰**、且已进入 `arrival_eps`）。

### 7.1 代价（实测，必须知道）

删掉它的第一个版本**把世界打崩了**：1000 回合后只剩 **1–4 个势力有城、5–8 个永久亡国**
（seed 42 只剩 1 家）。机理：战争拆掉最后一座城 → 无产出 → 库存被维护费抽干 →
全舰队生锈拆解 → **永远回不来**（无城不能造舰、无舰不能殖民）。

补的一条例外（**机制选择，可翻转**）：**无活城的势力（流亡舰队）不因维护费被拆解**——
维护费是**港口/后勤**成本，没有港口就无从「欠费拆解」（`step_upkeep`）。理由不是平衡，而是
**让「重建靠航行」这条机制真的可达**：舰队必须先活到能开过去。补上之后世界整合到
**3–4 家有城 / 4–6 家亡国**（seed 1: 3/6、seed 7: 3/6、seed 42: 4/4）。

### 7.2 一个真实的机制发现：亡国**不是**终局

实测 seed 1 里「城舰两空」的联合国/无国界科学组织**反复复生**。原因不是 bug，而是**离心倒戈**：
`CityDefected` 把一座**已存在**的城交给**意识形态最对立者**，**不需要舰**。所以
「没有舰就无从**建**城」成立，但「没有舰就永远没有城」**不成立**——认同你的城民还在。
这条现在是明确的机制事实，守卫也按它改判（见 7.3），不要再写成「亡国是终局」。

### 7.3 守卫改判：机制不变量 vs 平衡目标

用户指示「先确立机制的正确性」——所以把旧守卫里混在一起的两种东西**拆开**：

**机制不变量（继续断言，`cargo test` 必须绿）**
* `city_founding_requires_a_ship_there`（**新**）：凡出现 `ColonyFounded`，其 owner 在该回合
  结束必须仍有活舰——**没有凭空变城**。这是 `step_resurgence` 那条守卫的**正确替代**。
* `coalition_mechanism_is_alive`（**新**）：长局里反制联盟真的成立、霸权真的被封锁（机制是活的）。
* `no_nonfinite_over_long_run`：不再断言「舰不能全没了」——舰队被战争清空是**合法状态**
  （只要还有活城 + 造船区就能重造，实测 seed 42 r816 前后就是这样），改成断言
  **世界不能变成「没有任何活城」的僵局** + 打印零舰回合数。
* `same_seed_reproduces_identically` / `world_value_is_bounded` / `test_power_statistic_matches_game_logic`：原样。

**平衡目标（`#[ignore]` 明确挂起 + 把实测值写进注释，不删不放宽）**
* `world_is_multipolar`：城占峰值 < 0.85 + 后半程最强者轮换。实测已破（整合到 3–4 家、
  峰值 1.000、seed 1 后半程锁死为俄罗斯）。要变绿得补**平衡手段**（例如让战争更倾向于
  「易主」而不是「拆平」、给劣势方更强的复垦激励、或调维护费/治理曲线），
  **不是**恢复凭空造城。
* `probe_world_health`（`--ignored`）：打印 1000 回合后有城势力数 / 亡国峰值 / 城占峰值。

## 1. 实测基线（`tests/trade_probe.rs`，3 seed × 400 回合，main@`e9c8cf2`）

复现：`PROBE_ROUNDS=400 PROBE_SEEDS=1,42,12345 cargo test --test trade_probe -- --ignored --nocapture`
（探针口径与 `step_market` 逐字同源：`need` 只由**已定舰级**的建造区决定；`surplus` 只算不在
`need` 里且高于 `working_buffer` 的部分。）

### 1.1 三个洞

**洞 1 — 市场是常数价格的无限供货商。** `ResourceDef.value` 是写死的常数（`config/game.ron`
`resources:`），`step_market` 只做一件事：把船坞需要的矿补到 `working_buffer = 6.0` 单位，
用「不在 need 里且高于 6 单位」的富余按 `spread = 0.15` 折算。**没有卖方、没有库存上限、
没有价格变化、没有对手方**。所以「缺某种矿」只会让你买得少一点，**永远不会更贵**。

**洞 2 — 市场实际上几乎不成交。** 因为「能卖的东西」被定义为「不在 need 里的矿」，而多数
势力只有 3–5 种矿、其中大半**就在 need 里**，所以卖方一侧基本是空的：

| 势力 | 成交比例「近 0」回合 / 有船坞回合 | 缺料时「卖无可卖」 |
| --- | --- | --- |
| 中国 | 289/396、388/399 | 149/150、228/230 |
| 星系矿业 | 386/397 | 222/224 |
| 深空运输联盟 | 400/400、400/400 | 388/388、190/190 |
| 无国界科学组织 | 366/397、397/397 | 261/264、394/394 |
| 欧盟 | 169/400（最好的一档） | 26/26 |

「缺料且卖无可卖」几乎等于「缺料」本身——**一个势力一旦缺料，它同时也没有东西可卖**，
于是市场在最需要它的时候正好失效。9 个势力里没有一个能靠市场稳定补货。

**洞 3 — 最稀缺的矿没有任何门槛作用（最要命）。** 全世界 400 回合的累计产出：

```
铁=14812 硅=11680 碳=10816 水冰=9442 氢=3580 钍=3140 铀=2263 铂=1801 甲烷=509 金=282 氦-3=200
```

`金`（0.7/回合）与 `氦-3`（0.5/回合）比 `铁` 稀缺 **50–74 倍**；`氦-3` 在 30–67/400 个回合里
**全世界产量为 0**。而按 `config/game.ron` 的组件表，恰恰是它们决定军备上限：

| 组件 | 成本 | 作用 |
| --- | --- | --- |
| 等离子炮 | 氦-3 3.0 + 金 1.5 | 对盾强、射程远 |
| 能量护盾 | 铂 2.0 + 氦-3 1.0 | 吸收池 |
| 轨道炮 | 铀 3.0 + 铁 2.0 | 远程拆甲重炮 |
| 近防炮阵 | 金 2.0 + 硅 1.0 | 拦导弹 |
| 复合装甲 | 硅 4.0 + 钍 2.0 | 高级防护 |

但 `spawn_ship` 的 `commit_spend` 把扣款**钳在 0**（`(e - c).max(0.0)`）——**穷到 0 也能装齐
等离子炮 + 护盾**。于是「氦-3/金 是太阳系最稀缺的东西」在模拟里**毫无后果**。

> 结论：稀缺→价格→禁运→战斗力这条链，**每一环都不存在**。用户要的「真实有力」，
> 缺的不是一个旋钮，而是一条链。

### 1.2 顺带量到的（与本次设计有关）

- **结构依赖已经天然存在**（t=0，全部舰级需求 {氦-3,硅,碳,金,铀,铁,铂}）：

| 势力 | 必须进口 | 可出口 |
| --- | --- | --- |
| 联合国 | 硅 碳 金 铀 铂 | — |
| 欧盟 | 氦-3 硅 碳 金 铁 | 氢 水冰 甲烷 |
| 无国界科学组织 | 氦-3 硅 碳 铀 铁 | 氢 水冰 |
| 深空运输联盟 | 氦-3 碳 金 铀 铁 铂 | 钍 |
| **行星X崇拜教** | **氦-3 硅 金 铀 铁 铂** | **无** |
| 俄罗斯 | 氦-3 铀 铂 | 水冰 钍 |

  崇拜教（只有伊克西翁一座城、只挖得到碳）是**全世界依赖度最高的势力，且无货可出口**，
  而它恰好在 MOND 异常带里（r≈30–49 AU）。「唯一能可靠穿越异常区的势力，自己却什么都缺、
  什么都得买」——这是主线级的剧情张力，M6 就该建在这上面。
- **世界库存价值 400 回合涨 10 倍**（222 → 2326 / 973 / 1938）：开采是「面积×产出」无限，
  所以铁/硅/水冰**长期不可能真稀缺**。这条决定 D3（要不要同时做矿藏耗竭）。
- **流亡态真实存在且很短**：最长连续无城 = 1–13 回合，且**从未出现「无城且无舰」**。
  即每逢亡城，势力都还握着舰队——「用贸易/承运养活一支无立足点的舰队」在数据上是**有载体的**。

## 2. 设计（M1–M7）

原则：全部确定性（**不动 `Prng` 流**；需要随机处一律用 `(round, seller, buyer, rt)` 哈希），
新参数全部进 `config/game.ron` + `meta_value` 暴露给 agent，长局守卫不许退化。

### M1 市场状态进 `State`
`State.market: MarketState`（`#[serde(default)]`）：
`offers: Vec<Offer { seller, rt, amount, ask }>`（挂单，按卖家记账——见 M5）、
`stock: ResourceMap`（公共仓）、`price: ResourceMap`（本回合价）、`settled: BTreeMap<rt, f64>`（成交量）、
`avg_demand: ResourceMap`（滑窗平均消费，用于 M3）。

### M2 挂单来自真实产出
每回合每势力计算「可出口量」= 非 `need` 资源 − `reserve_rounds ×` 自己近 N 回合的消费，
挂进 `offers`（记名卖家）。**供给从此是有限的、来自别人的**，不再是无限贩卖机。

### M3 价格发现（这就是「超高价」）
```
scarcity = clamp( (target_stock / max(stock + on_order, eps)) ^ price_alpha, price_floor, price_ceiling )
target_stock = avg_demand[rt] * coverage_rounds
price[rt]   = base_value[rt] * scarcity
```
配置（建议初值）：`coverage_rounds = 8`、`price_alpha = 0.5`、`price_floor = 0.4`、
`price_ceiling = 8.0`。仓空 → 价格顶到 **8×** 基价；仓满 → 折到 0.4×。
价格写进 `State.market.price`，**agent/Web 可直读**（「氦-3 现在是 7.4×」）。

### M4 成交是有配给的
买方按「缺口比例」分配，**仓里有多少卖多少**。买不到就是买不到——这是「不卖给你」的
**非政治版**（市场没货了）。这一档单独就能让 `氦-3` 在全世界断产的回合真的卡住军备。

### M5 禁运 = 卖家不接你的单（「不卖给你」的政治版）
`fn offers_visible(seller, buyer, rt) -> bool`：
- 交战（关系 ≤ `war_threshold`）→ **全面禁运**；
- `coalition_of(hegemon)` 成员 → 对霸权禁运 `strategic` 类；
- 关系 ≤ `embargo_relation`（建议 −12）→ 禁运 `strategic` 类。

**关键实现约束**：禁运货**必须不进公共仓**。所以挂单按 `(seller, rt)` 记账、买方只挑
「可见的挂单」——否则被禁运的货经公共仓转手，封锁形同虚设。这一条同时**取代**现在
`balance.sanction_trade_mult = 0.3` 那个「把额度打 3 折」的钝旋钮（那是「少卖一点」，
不是「不卖」）。`strategic` 集合建议 {氦-3, 铀, 钍, 金}。

### M6 运费与 MOND（把主线接上经济）
成交价 += 运费：`freight = freight_base + freight_per_au × 卖方交割城到买方首都的距离`。
**穿越 28 AU 异常带**再乘 `mond_freight_mult`，且非 master 有丢货率（确定性哈希决定）。
→ 崇拜教是柯伊伯带唯一可靠承运人，天然成为中间商；深空物资真的贵。这是 MOND 除
「导航偏移/战斗光环」之外的**第三条通道（经济）**，与 `notes/mond-anomaly.md` 的待办一致。

### M7 让稀缺真的咬到战斗力（链的最后一环）
把组件成本从「付得起就付」改成**硬门槛**：`choose_loadout` 只能选**库存此刻付得起**的组件；
付不起就退到廉价档（`铁/碳` 的轨道炮-拆甲炮 / 装甲夹层）。
→ 缺氦-3/金 ⇒ 只能装动能炮和夹层 ⇒ 舰队**真的更弱**、维护费也更低。
这是「稀缺 → 高价 → 买不到/买不起 → 舰队质量下降」这条链的终点，也是让制裁「有力」的地方：
不用夷平你的城，只要**没人卖你氦-3**，你的主力舰自己就退回廉价配置。

### M8（候选，与「重建」直接相关）
无立足点势力可以**承运**（M6 的运力服务）挣收入，也可以**买地/租地**（向某势力购买一处
定居点的殖民权，走一个真实的禁运可见的交易）——**重建所需的材料与土地都必须买得到**，
于是「重建」不再是凭空变城，而是「花钱（且要有人肯卖）买回来的立足点」。见 D5。

## 3. 决策点（**待用户拍板**）

- **D1 范围**：先做 M1–M5 最小闭环（价格 + 配给 + 禁运），还是一次做到底（含 M6/M7）？
  建议：M1–M5 + M7 一次做（M7 是「有力」的关键，不做等于白做），M6 第二步。
- **D2 谁供给**：只有势力？还是加**中立自由港**（世界里已有「卡戎深空港」「灶神星转运港」
  这类名字）作为不被禁运的泄压阀（可被封锁/占领）？建议加，防「全世界互相禁运 → 僵死」。
- **D3 要不要同时做矿藏耗竭**（`economy-depth.md` 第 1 条）：不做则铁/硅/水冰价格长期贴地板
  （实测 400 回合世界价值涨 10 倍），只有 1–2 个来源的氦-3/金/铀 会真稀缺；做才能让「缺矿」
  在千回合尺度上一直是主题，但要防热寂。建议：**先不做**，但价格公式按「仓/需求」写，
  以后加耗竭不改结构。
- **D4 禁运尺度**：战争=全面、联盟遏制=只禁战略物资（建议），还是一律全面？
- **D5 和 `step_resurgence` 的关系**（用户的核心不满）：(a) 保留现状；(b) 收窄成「只在自己
  残骸足迹上重建 + 要买得到材料 + 要有舰在附近」；(c) 删掉，允许**亡国**（势力真的消亡，
  或退化为无城流浪舰队/海盗），把 `zombie_factions_are_bounded` 改成「亡国是干净结局」。
  建议 (b)：(a) 太反科学，(c) 会改动「多方参与」的世界前提（现在 9 个势力永不全灭）。

## 5. 风险

- **死锁/热寂**：全世界互相禁运 → 谁都造不出舰。泄压阀 = 中立港 + 只禁战略物资 + 禁运随关系恢复自动解除。
- **价格正反馈**：囤积 → 天价 → 更囤积。用 `price_ceiling` + 价格向均衡回归，别做成投机模拟。
- **确定性**：任何新决策都不许动 `Prng` 流（否则 `same_seed_reproduces_identically` 与既有
  轨迹全变）；需要随机处用哈希。
- **schema**：新字段一律 `#[serde(default)]`；资源 key 用中文可读名（见 `wysiwyg-resource-keys.md`）。
