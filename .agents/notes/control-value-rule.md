## 0. 一句话

**归属与取值是同一条链上的同一件事**：谁"有意见"谁说了算。`Inherit` **不是第三种决策者**，
只是"我没意见"；所以它既不参与归属、也不参与取值——而 `Auto` 那一档的**值**存在**逐舰叶**里
（系统每回合现写那片叶）。**没有第二种解释，也没有歧义。**

## 1. 规则（原文三句，合成一句）

* **归属**：沿链 `逐舰叶 → 出厂图 → 舰队默认 → 势力 scope → 全局 scope`（风格三轴没有"图"这一层）
  取**最具体的有意见者**（`Inherit` = 不是意见）；一路没人有意见 ⇒ `Auto`。
  这就是 `State::ship_control` / `blueprint_control` / `*_control` 那一族函数，一行 `resolve_chain`。
* **写值即接管**：通过补丁（`--apply` / web / kit）**写值而不给 `mode`** ⇒ 隐含 `Player`
  （否则"命令已下达"是假象），回执里有一条 `took_over`。`--apply` 的每条 `apply_*` 助手同源
  （`src/control.rs` 的 1142 / 1210 / 1254 / 1305 / 1355 / 1811 / 2049 / 3597 等）。
  系统自己写值时给 `Auto` / `Inherit` 只表达**归属**，不改变这条规则。
* **取值**：`Auto` 这一档没有独立的"值存储"——它就是**逐舰叶**（`autocontrol` 每回合现写的那片）。
  于是：
  1. 叶**存在** ⇒ 叶里的值就是"系统当前的值"；
  2. **唯一的例外**：叶写着 `Inherit`（= 它不主张归属）**而**链上有 `Player` 的出厂图 / 舰队默认
     ⇒ 用那个**玩家层**的值（更具体的"有意见者"胜）；
  3. 叶**不存在** ⇒ 同上看上面两层；风格三轴再兜底到**出厂记录值**
     （`Ship.doctrine` / `kiting` / `freighter`），而**指令轴没有记录值** ⇒ 出事可说（读面 `null`，
     调用方按 `Idle`）。

**一句话版**：「最具体的有意见者」同时决定**归属**与**值**；`Inherit` 让位给上面的 `Player`，
`Auto` / `Player` 就是它自己说了算。

## 3. 三条"看起来像歧义"的旧账，逐条结清

1. **§10.4「恢复继承撤不掉叶里的值」** —— 这是**交互层的期望落差**，不是模型缺陷：那个按钮想说的
   是"忘掉我写的这个数"，而按模型 `Inherit` 只表示"我不主张归属"，于是值落回"系统当前的存储"
   = 玩家刚写进去的那个数。出口是**删叶**（`{"ship":"X","remove":true}`，方案 A 已落地，
   UI 的按钮现在叫「恢复出厂值」）。
2. **「文档说『叶不存在 ≡ 叶写 Inherit』，但取值不等价」** —— **文档只写了归属那一半**。
   §11.5 已把 `src/control.rs` 那段读面文档改成实话；本文 §1 是完整版。
   正确的说法不是"两者在取值上不等价"（那听起来像 bug），而是：
   **`Inherit` 让位给上面的 `Player`；一路没有 `Player` 时，"系统当前的值"就存在于那片叶里。**
3. **「势力级默认叶只有 `Player` 才供值」** —— **不是特例，是"值存在哪"的必然**：`Auto` 档的值存在
   **逐舰叶**里，势力级默认叶在 `Auto` 档没有存储可言（自动控制只写逐舰叶，从不写它）
   ⇒ 只有玩家自己声明（`Player`）时它才供值。web 的提示已经按这个措辞写（§12.2 的记录）。

## 4. 裁决（2026-10，用户）

* **模型与取值规则不动。** 不采用 方案 B / B3 —— 它不是"修歧义"，只是**换一种表达**
  （把 AI 写的叶从 `Inherit` 改标 `Auto`）；代价很实在：更具体的层胜 ⇒ 玩家钉的 `Player`
  **舰队默认**会被 AI 的逐舰 `Auto` 叶压住，§8「改一处管全舰队、新舰自动继承意图」当场失效
  （§2 表格第 2 行就是它）。
* **AI / 系统写"当前值"继续用 `Control::inherit(值)`**：这不是权宜，是**承重**的——正因为那片叶
  "不主张归属"，玩家的 `Player` 舰队默认才管得住全舰队。正在做的「风格轴执行者」与
  「`Auto` 设计图执行者」都按这条写。
* 剩下要做的只有**把规则说全**：§1 这段写进 `src/control.rs` 顶部文档与 `agent-play.md`，
  并把把这件事描述成"坑 / 歧义"的段落改写掉（`control-live-layers.md` §10.4 与 §12.2 的口径）。
* 那次"量 B3 代价"的探针（`scratch/b3-probe`）**已叫停并删除**（未产出数字）：结论不依赖它。
