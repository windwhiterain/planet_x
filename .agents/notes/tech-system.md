## 1. 核心主张

> **MOND 是「真知识」的门径；牛顿引力是表层近似。**
> 科技 = **一条干线（道：掌握度）＋ 挂在它上的应用（术：能造什么）**；
> 思潮轴「科学↔技术」是道与术的分岔阀。

三层含义，逐层可独立实现：

| 层 | 内容 | 一句话 |
|---|---|---|
| **道** | `mond_control ∈ [0,1]`（每势力一个连续标量） | **你的舰队能走多深** |
| **术** | 由道派生的、**按概率习得**的应用项（模块／结构／舰级设计） | **你能造什么** |
| **势** | 道与术在世界上的**争夺**（在场、掠夺、条约、扩散） | **谁在领跑、谁会掉队** |

两条贯穿纪律（本仓库既有裁决，不是新规矩）：

1. **一切效果走概率分布，不新增断崖**——掌握度**连续地**改「一次尝试的胜算」，
   而**不是**在某个档位上给一条 `if`（`AGENTS.md`「默认用概率分布」；
   `ideology-roles.md` §8 踩过的坑：断崖与全队同向抖动）。
2. **骰子走 `derived_roll(势力, 键, 回合, 用途)`，绝不消费主 `Prng`**
   （`src/sim/mond.rs:99`）——否则「多派一艘船」会改变整个世界后续的掷骰。

## 2. 轴心量：`mond_control`（道）

### 2.1 公式（对现状是**一行推广**）

```text
现状：  drift = depth × drift_per_au × roll^shape            （masters 直接早返回 0）
推广：  drift = depth × drift_per_au × (1 − control) × roll^shape
        p     = min(1, (arrival_eps / (depth × drift_per_au × (1 − control)))^(1/shape))
```

* `control = 1` ⇒ 偏移恒 0 ⇒ **就是今天的 cult**（指哪打哪）；
* `control = 0` ⇒ **与今天逐位相同**（这是 M1「零回归」可验收的原因）；
* 中间连续过渡，**没有任何档位判断**。

**前沿海拔**（p = 1 的半径）随掌握度外移——这是整根干线最直观的读数：

| `control` | 0.00 | 0.35 | 0.70 | 0.90 | 0.98 | 1.00 |
|---|---|---|---|---|---|---|
| `r* = radius + eps/(drift×(1−c))` | **30.0** | **31.1** | **34.7** | **48.0** | **128** | ∞ |

**每个天体的实测胜算**（`eps = 0.06`、`drift_per_au = 0.03`、`shape = 1`；
近日/远日 = `a(1∓e)`，轨道参数取 `src/world.rs:465-533`）：

| 天体 | r 近日→远日 | p @0 | p @0.35 | p @0.70 | p @0.90 |
|---|---|---|---|---|---|
| 海王星（欧盟） | 29.8 → 30.3 | 1.00 / 0.86 | 1.00 | 1.00 | 1.00 |
| 冥王星（俄罗斯） | 29.6 → 49.3 | 1.00 / 0.09 | 1.00 / 0.14 | 1.00 / 0.31 | 1.00 / 0.94 |
| 伊克西翁（崇拜教） | 30.2 → 49.2 | 0.92 / 0.09 | 1.00 / 0.14 | 1.00 / 0.31 | 1.00 / 0.94 |
| 妊神星（星系矿业） | 35.0 → 51.4 | 0.29 / 0.09 | 0.44 / 0.13 | 0.95 / 0.28 | 1.00 / 0.85 |
| 创神星（星系矿业） | 38.2 → 52.7 | 0.20 / 0.08 | 0.30 / 0.12 | 0.66 / 0.27 | 1.00 / 0.81 |
| 阋神星（星系矿业） | 38.0 → 97.6 | 0.20 / 0.03 | 0.31 / 0.04 | 0.67 / 0.10 | 1.00 / 0.29 |

读法（**这就是「时代步伐」**）：L0 的势力**只能**摸到前沿 30 AU 内的近日段；
爬上 L2 后柯伊伯带从「要试十几次」变成「一个月内到位」；L3 之后**远日段也打开**。
而**永远没有一步是「解锁了才准去」**——只有「去几次才成」的差别。

### 2.2 配置形态（**已落地**）

```ron
mond: (
    radius: 28.0,
    drift_per_au: 0.03,     // 上界再乘 (1 − 掌握度)
    drift_shape: 1.0,
    // 取代 masters: ["行星X崇拜教"]——开局掌握度（0..1）。崇拜教仍是 1.0（现状零回归），
    // 其余势力从 0 爬。名单语义从「布尔特权」升级为「初始值」。
    initial: { "行星X崇拜教": 1.0 },
    knowledge: ( presence_ref: 2.0, drift_rate: 0.03, depth_weight: 0.25 ),   // 见 §3.3
),
```

**调用面改动**（已做）：`mond_drift(config, control, dest, roll)` /
`mond_arrival_chance(config, depth, control)` / 新增 `mond_frontier(config, control)`
——**fid→control 的查表移到调用方**（`sim::mond_control(state, fid)`），
所以 `mond.rs` 仍是**无状态纯函数**，`State` 不必渗进几何层。
市场那两处布尔（丢货免疫、承运抽成）改为**连续**：`丢货 ∝ (1 − max(买卖双方掌握度))`、
`承运人 = 掌握度最高者且抽成 ∝ 它的掌握度` ⇒ **最后一条布尔判据消失**，
「写死的名单特权」不再有任何残留。

## 3. 知识从哪来、怎么失去（势）

### 3.1 五个渠道（**用户裁决：第一版只做第一条**）

| 状态 | 渠道 | 口径 | 对应既有机制 |
|---|---|---|---|
| `[x]` | **在场观察**（科学端） | 异常区内自己的活舰，每艘 `1 + 深度 × 0.25`（越深越值钱） | 思潮 `science_tech` 的 `sci_ships`（`ideology.rs:127`）同一口径 |
| `[ ]` | **开采/驻留**（技术端） | 异常区内**城市**（人口×面积） | 同轴的 `tech_cities`（`ideology.rs:127`）＝ spec「开采MOND区域资源」 |
| `[ ]` | **残骸回收** | 击沉掌握度更高的势力的舰 ⇒ 按**缺口比例**回收一部分 | 现成的 `ShipDestroyed.by`（稀疏历史里已有） |
| `[ ]` | **条约/剧情** | `TransferControl` / `GrantControl` 效果 | `StoryEffect` 的既有形状；`GrantShip` 的先例 |
| `[ ]` | **扩散**（待裁决 3） | **沿实际接触**（承运关系／同城／条约）向低者缓慢渗漏，**不是**全世界平均 | 市场承运关系（`market.rs:234-281`）＋关系表 |

**只做第一条的直接后果**：研究**没有建筑、没有预算**——知识只跟着舰队的**地理位置**走。
于是「不去就学不会」不是口号，是一条硬事实（§9 的实测：没人常驻 ⇒ 全体锈回 0）。

### 3.2 「活知识」与「死知识」（待裁决 9）

| 状态 | | 载体 | 会不会丢 |
|---|---|---|---|
| `[x]` | **道**（掌握度） | 人／舰队／在场 | **会锈**：不在场就按 `drift_rate` 向 `target` 回落（与思潮同一个松弛样板，`ideology.rs:134-143`） |
| `[ ]` | **术**（已习得的模块／结构） | 图纸／建筑 | **不锈**：一旦习得永久保留（否则「科技」退化成「驻军」） |

这条不对称是**故意的**，而且它就是剧情：**术留在图纸上，道留在人身上**。
崇拜教的圣所被夷平之后，它的模块图纸还在、但它的人去不了深处了。

**实现代价（实测，见 §9）**：只有「道会锈」时，锈是**主导**项——没人常驻就全体回 0。
所以这条不对称要成立，就必须先有「**让舰队去蹲异常区的动机**」（§9 的待办）。

### 3.3 掌握度怎么涨（**已落地**）

```text
presence   = Σ 自己的活舰(在带内) [1 + 深度(AU) × depth_weight]     // 唯一渠道，见 §3.1
target      = 1 − exp(−presence / presence_ref)                     // 指数饱和
够格        = presence ≥ mastery_presence                          // 「一支真的常驻深空的编队」
够格的回合  : control += 1 / mastery_rounds                        // 爬满 ⇒ 正好 1.0 ⇒ **棘轮锁住**
其余回合    : control += drift_rate × (target − control)            // 与 step_ideology 同形
棘轮        : control ≥ 1.0 ⇒ **永不下降**（用户裁决）
习得术（未实现）：每回合对每个「未习得」的项抽一次签（derived_roll）
        p = σ((control − need) / width)                             // need = 要求档，width = 软宽度
```

常数（`config.mond.knowledge`，都是**我自己定的**、一格一旋钮）：`presence_ref = 2.0`
（≈ 一两艘舰驻在带内就爬到目标的 63%）、`drift_rate = 0.03`（半衰期 ≈ 23 回合）、
`depth_weight = 0.25`（深处一艘 = 浅处的好几艘）、`mastery_presence = 12.0`（学满的资格）、
`mastery_rounds = 48`（够格要持续 48 回合才爬满）。

* **`target` 用指数饱和而不是线性累加**：投入翻倍 ≠ 进度翻倍，越接近满越难——天然给领跑者刹车；
* **学满要靠「持续够格」而不是一次巧合**（第一版写成「够格就**直接**到顶」，实测立刻出事：
  seed 7 里俄罗斯与深空运输联盟各只在 6–7% 的回合有舰在带内，却都靠某一回合恰好凑够而
  **永久**当上 master，r240 双双到 1.0。一回合的巧合不该换来永久垄断 ⇒ 改成
  「够格的回合各走 `1/mastery_rounds`」，于是踩中一次只值 0.021）；
* **术靠抽签而不是阈值**：`control` 刚好压在 `need` 上时只是「有机会」，不是「开关」；
  这也是「研究要时间」最便宜的写法（每回合一枚新骰子，**不会被同一枚骰子锁死**）；
* **正反馈的刹车早就存在**：`IdeologyDebuffConfig` 对优势端思潮（科学端在列）的
  自平衡忠诚惩罚（`config/game.ron:377-395`、`src/sim/governance.rs:84-134`）。
  于是闭环的**意图**是：**派舰进异常区 → 科学思潮↑ → 在场学习更快 → 掌握度↑ → 更能呆在深处**，
  而这条正反馈把它的忠诚烧掉。**两条旧机制咬合，不新增平衡器。**

给它们加一层 `if` 就是给世界加一层断崖。做成「贵 + 要抽签」，AI 的**现有那把尺子照旧能用**
（`build_rounds` 算的回合数自然变长），不必重写决策。

**时代的三个样板**（把 `eras-technology.md` 的三条落到这根轴上）：

|---|---|---|

## 5. 与既有系统的咬合（改之前必须知道的六处）

1. **政治议题**：`political-system.md` §7 要的 `mond_control` **就是本文这个量**——
   两处写法必须**合成一个**（那篇的「可经研究/掠夺/交易上升」是本文 §3.1 的渠道表），
   它的 `exclusivity`（§15 待定③）由本文给出答案：**奖品 = `mond_control` 与它开出来的前沿**。
2. **思潮口径**：`science_tech` 现在是二分代理（`异常区舰数 − 异常区城数`）。
   本文**不改它的口径**，而是**反过来读它**（用作 §3.1 两个渠道的权重）——
   改口径会重新平衡治理/外交/角色轴一整串下游（`governance.rs:114`、`relations.rs:161`、
   `freight.rs:129`），收益不抵风险。
3. **承运/运费**：`market.rs` 那两处布尔**已改连续**（`丢货 ∝ (1 − max(双方掌握度))`、
   `承运人 = 掌握度最高者、抽成 ∝ 它的掌握度`）——**不新增第二把尺子**，
   而且崇拜教的承运垄断**确实还在**（实测 seed 7 / 600 回合：累计抽成 17.41，其余八家
   合计 0.01；`tests/tech_probe.rs probe_mond_carrier`）。
4. **矿藏耗竭**：`economy-depth.md` 的耗竭按 D3 裁决「**先不做**」；矿藏红利做成**产出乘子**，
   将来加耗竭时结构不变（乘子乘在产量上）。
5. **refit（老舰换新图）**：仍归 `military-combat.md`，本文**不碰**。
   但要注意它一旦落地，「术」的新模块就有了第二条传播路径（**旧舰换装**），届时
   `requires` 要一并管住，否则「新模块」可以绕过习得直接装上。
6. **设计图的分工**：图**不存数值**（`blueprint.rs:19-22` 的裁决），所以
   「专精」永远由**模块组合**表达——本文的「术」正好是**新增模块**，不是图里的字段。

## 9. 实测（`tests/tech_probe.rs`，600 回合 × seed 7/42）

> 下面这张表是 **M2 当时**的数字（那时崇拜教还有 `initial: 1.0` 这个开局特权）。
> 「特权删掉」+ 棘轮落地之后的**当前**状态见 **§9.2**。

**渠道是真的、但世界没有理由用它**——这是本轮量出来的**唯一**结论：

| 观测 | seed 7 | seed 42 |
|---|---|---|
| 势力「有舰在带内」的回合占比 | 全部 ≤ 8%（崇拜教 **1%**） | 全部 ≤ 5%（崇拜教 **2%**） |
| 掌握度峰值 | 美国 0.53、崇拜教 1.00（开局） | 欧盟 0.51、联合国 0.45、崇拜教 1.00 |
| **终值（r600）** | **全部 0.00** | **全部 0.00** |
| 越过 0.35 的势力 | 2 / 9 | 3 / 9 |

机制正确性可以从这条轨迹直接读出来：**崇拜教 r40 = 0.31 ≈ 1.0 × 0.97⁴⁰**——
它的三艘舰在头几回合就被打光（它是全世界围攻的对象），此后 `presence = 0`，
掌握度就按 `drift_rate` 精确地锈下去。**「不去就学不会」成立，而且是双向的。**

于是暴露出**设计缺口**（不是 bug）：`step_knowledge` 只是「舰队在哪」的**被动读数**，
而自动控制**没有任何理由**把舰队留在 28 AU 之外——深处既没有矿（矿藏红利未做）、
也没有仗（带内城市守不住）、更不影响造舰。**一个没有动机的渠道等于没有渠道。**

**9b 的三个候选**（这是设计裁决，不是调参）：

| 方案 | 内容 | 代价 |
|---|---|---|
| **(a) 观测编队**（我倾向） | 给角色轴加**第三态**（运输/战斗/**观测**），配额与集货同源：`缺口 = 目标在场强度 − 现有在场`，按**缺口抽签**派人（照抄 `ideology-roles.md` 的机制） | 动 spec 的「战斗/运输」二态 + 控制面第三条轴（web/kit 都要跟） |
| **(b) 只在「有余力时」派** | 不新增轴：自动控制把**闲舰**（无仗可打、无货可运）按概率派去最近的带内天体待命 | 最轻；但「观测」是副产物，说不清谁在观测 |
| **(c) 让 `science_tech` 思潮自己驱动** | 科学端思潮 = 研究偏好 ⇒ 让**科学端的势力**按倾向派观测舰（思潮已经有了，只缺执行者） | 复用「思潮 → 行为」的既有范式（`ideology-roles.md` 就是样板）；但要防「思潮自己饱和」（上一轮已发现 `nature_colony` 全部顶到 0.99 的教训） |

### 9.1 副作用：世界在 r240–400 之间「舰队全灭」

M2 之后有一条守卫翻红（`horizon_mid::long_run_produces_customized_ships`），量清楚之后
**不是机制失效，而是它押的那个轨迹事实变了**：同一段探针在两条树上各跑一次（400 回合 ×
seed 7/42）——

| 树 | 出厂舰（带设计图） | 活舰峰值 | **末回合活舰** |
|---|---|---|---|
| `main`（`23bdb25`） | 206（—）/ 230（—） | 81 / 60 | **0 / 27** |
| 本分支（M2 之后） | 105（100）/ 92（87） | 46 / 40 | **0 / 0** |

两条树上**选装机制都正常**（出厂的舰几乎全都带组件），差别只是末回合场上还剩几条舰。
判据因此从「末回合快照」改成「**整局里出现过**」——这个口径比原来更不容易空转，
检验的是同一件事（改动写在用例的文档注释里，附上面这张表）。

**顺带记一条平衡观察（不是本轮目标）**：两个种子在 r400 都跑成**空场**（全世界没有一艘活舰），
而 r240 的 digest 里还有 15–52 艘 ⇒ 这个世界的战争烈度让舰队在中局之后被彻底打光。
这与上一轮「`nature_colony` 全体饱和到 0.99」「深空城守不住」是同一批长局现象，留给平衡轮。

| 崇拜教 | 0.05 | 0.00 | 1% |

**没人到顶**（第一版「够格就**直接**到顶」时，上面两家曾在 r240 双双到 1.0 并永久独占——
那正是「一回合巧合换永久垄断」的 bug，已改成持续 48 回合）。所以现在的世界是：
**干线连着、渠道通着、但没有人去拿**。这不是平衡问题，是**动机缺失**——§11 就是补它。

**对崇拜教的影响（要你过目）**：它不再是天生 master，于是

## 11. 观测编队（裁决 9b = **(a)**）的实现地图

用户裁决：**角色轴加第三态**（运输 / 战斗 / **观测**），配额与集货**同源**。
下面是落到这个代码库上的具体做法（照抄「集货定编」那套已经验证过的形状）：

| 件 | 内容 | 挂点 |
|---|---|---|
| **轴的形状**（**要你拍一下**） | ⓐ 把现有 `Control<bool>` 的角色轴**变成三值枚举** `Role { War, Freight, Observe }`（忠实于「第三态」，但 `wire.rs` 的 `freighter: bool`、web 的 `freighterEditor`、kit 的 `set_freighter` 三端字段类型全要改）／ⓑ **并列加一条 bool 轴** `ship_observer`（照抄 `ship_freighter` 的整条流水线，改的是同一批文件但**不动**现有轴的语义） | `src/model/control.rs`、`wire.rs`、`apply.rs`、`view.rs`、`projection.rs`、`web/static/app.js`、`play/planet_x_ctl` |
| **配额** | 目标**在场强度** = `mastery_presence`（学满的资格）；缺口 = 目标 − 现有在场；换算成头数用「每艘在选定深度的价值 `1 + 深度 × 0.25`」 | `autocontrol/knowledge.rs`（新，与 `freight.rs` 同形） |
| **派谁** | 与集货**同一条纪律**：`p = 缺口 × 本舰的票 ÷ 同侧总票数`；票按**速度**（谁先到位）+ 现有深度（已经在那儿的别调回来）；`derived_roll(fid, ship, round, "observe")` | 同上 |
| **去哪** | 候选 = 带内天体，取 **`深度 × p(深度, control)`** 最大者（期望深度收益；复用 `mond_arrival_chance`，不新造尺子）。凡人前沿 30 AU ⇒ 一开始只能蹲海王星/冥王星/卡戎，掌握度上来了才轮得到创神星/阋神星 | 同上 |
| **行为** | 观测舰的指令 = `Move`/`Dock` 到那个天体；**本地有敌照旧开火**（沿用「角色只管派哪种活，不解除武装」的既有裁决）；若本地被压着打，先打完再回去 | `sim/military.rs` 的逐舰循环 + `autocontrol/tactics.rs` |
| **优先级** | **观测 > 运输 > 战斗**：观测是唯一「没有它渠道就空转」的角色；被选为观测舰的舰不进集货抽签（否则一本账两处花） | `autocontrol/freight.rs::assign_roles` 的调用点 |
| **玩家闸门** | 与角色轴完全一样：叶 `Player` ⇒ AI 不碰；舰队默认 `Player` ⇒ 整支舰队交回玩家 | `control/ship.rs` |
| **观察面** | `mond_ships_in_band`（已有）+ 新列 `observer_quota`（目标头数）与逐舰 `observer` / `observer_mode`（有效值与归属） | `projection.rs` |
| **验收** | ① 单测：缺口抽签的期望入伙数 = 缺口（照抄 `ideology-roles.md` 的做法）；② 探针：seed 7/42 × 600 回合里**至少一家**把掌握度推到 1.0（现在全是 0），且它成为唯一的承运人；③ 长局守卫不翻红；④ digest 换代 | 同 §7 的口径 |
