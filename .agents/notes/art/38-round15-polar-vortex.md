# 38 · 第 15 轮：极涡（V3）

用户待办 V3：**"极区没有特征"**（土星参考图上极区不是空白）。

## 改了什么

`art/inst/latbands.rs`：把 `|纬度|` 大于 0.66 的那顶帽子里的**纬度带**换成**极角上的环 + 螺旋**：

```text
cap        = smoothstep(0.66, 0.99, |纬度|)          // 极冠的权重
极角       = acos(1 − |纬度|)                        // 0 = 极点、π/2 = 赤道
polar_phase= 极角 · POLAR_RINGS + 经度 · POLAR_TWIST // 27 环/弧度 + 沿经度扭 0.55
wave       = wave·(1−cap) + polar_wave·cap
```

⚠ 为什么这里必须**换一套坐标**：上一轮把相位的纬度映射改成 `g(y)=y−0.24y³`（带往赤道集中），
它在两端斜率只剩 0.28 ⇒ **极点附近本来就没有起伏**（这正是 V3 的成因）。
用极角（`acos`）重新绕环，极区才有"绕极"的结构，而不是把纬度带硬拉平。

两块共用的旋钮都写了注释：`POLAR_RINGS` 是**每弧度**的环数（极冠只跨 `acos(0.66) ≈ 0.85 rad`），
`POLAR_TWIST` 给螺旋。

## 系统：`smoothstep` 进共用词汇

`px_field_alg::noise::smoothstep(edge0, edge1, x)`（`f32` 的对外版本；`edge0 == edge1` 按阶跃处理）。
实例与算子共用同一份 —— 与上一轮的哈希/值噪声/梯度噪声同一条理由（实例库只链 `px_field_alg`）。
`px_field_alg` 9 passed。
